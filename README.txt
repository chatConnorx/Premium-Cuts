PREMIUM CUTS — WEBSITE CONCEPT
Files: index.html (responsive English/Spanish concept website).

Included:
- Mobile-first premium barber design
- Sample service menu and sample prices
- Appointment request form with date/time and contact details
- WhatsApp contact link (generic until the real business number is added)
- Gallery placeholders
- Demo owner dashboard (footer link “Owner demo”, demo PIN 1234)
- Browser-local demo booking storage and JSON export

IMPORTANT: This is a front-end prototype, not a production booking system.
Demo requests are saved only in the browser/device used to submit them. They are not sent
to the barber and do not sync across devices. The dashboard PIN is not secure authentication.
No real availability calendar, database, notifications, payments or server-side double-booking
protection is connected. The demo prevents duplicate date/time requests only within that browser.
Prices, hours, location and availability are placeholders. Gallery blocks are design placeholders.
Replace these and add the business's real WhatsApp number before launch.

Publishing on GitHub Pages:
1. Upload index.html to the root of a public GitHub repository.
2. Repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Open the Pages URL. Use Chrome's Add to Home screen if desired.

Production readiness:
Connect a booking backend or booking provider, server-side availability validation, secure owner
authentication, confirmation/reminder notifications, spam protection, and a privacy notice with
GDPR-compliant handling before accepting real customer information.
